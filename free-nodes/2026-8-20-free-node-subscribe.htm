引言：为什么你需要小火箭？

在这个信息爆炸的时代，网络自由已成为现代人的基本需求。然而，地域限制、内容审查等问题常常成为我们获取信息的障碍。小火箭 Shadowrocket 作为 iOS 生态中最强大的网络代理工具之一，以其简洁的界面、强大的功能和稳定的性能，成为数百万用户突破网络边界的首选利器。本文将带你全面了解这款工具，从基础概念到高级配置，让你轻松掌握科学上网的艺术。

第一章：认识小火箭 Shadowrocket

1.1 什么是小火箭？

小火箭 Shadowrocket 是一款专为 iOS 设备设计的网络代理客户端，支持 Shadowsocks、Vmess、Trojan 等多种主流代理协议。它不仅能帮助你访问被限制的网站和服务，还能有效保护你的网络隐私，防止数据被窃取或监控。

1.2 小火箭的核心优势

  • 用户友好：界面简洁直观，新手也能快速上手。
  • 多协议支持：兼容 Shadowsocks、Vmess、Trojan 等多种协议，适应不同网络环境。
  • 灵活配置：支持自定义 DNS、规则设置和代理策略，满足个性化需求。
  • 隐私保护：通过加密传输数据，防止 ISP 或第三方监控你的网络活动。

第二章：下载与安装

2.1 官方渠道获取

小火箭 Shadowrocket 在 App Store 中提供下载，但由于某些地区的限制，可能需要切换 Apple ID 地区或通过其他方式获取。

步骤：
1. 打开 App Store，切换至支持 Shadowrocket 的地区（如美区、港区）。
2. 搜索 "Shadowrocket" 并购买（通常售价 $2.99）。
3. 下载并安装。

2.2 替代下载方式

如果无法通过 App Store 获取，可尝试以下方法：
- 通过第三方签名工具（如 AltStore）安装 IPA 文件。
- 使用企业证书版本（需注意安全性）。

⚠️ 注意：非官方渠道可能存在安全风险，建议优先选择正版。

第三章：基础配置教程

3.1 添加服务器

  1. 打开 Shadowrocket，点击右上角 + 按钮。
  2. 选择代理类型（如 Shadowsocks、Vmess）。
  3. 填写服务器信息（地址、端口、密码、加密方式等）。
  4. 保存并返回主界面。

3.2 连接与断开

  • 连接：点击服务器名称，再点击底部 连接 按钮。
  • 断开：再次点击 连接 按钮即可。

3.3 检查连接状态

  • 成功连接后，状态栏会显示 VPN 图标。
  • 可在 Shadowrocket 主界面查看实时流量和连接时长。

第四章：高级功能与优化

4.1 自定义 DNS

优化 DNS 可以提升解析速度并避免污染：
1. 进入 设置 → DNS。
2. 添加公共 DNS（如 1.1.1.1、8.8.8.8）。
3. 启用 DNS over HTTPS (DoH) 增强隐私。

4.2 规则配置

通过规则可以实现智能分流（如国内直连、国外走代理）：
1. 进入 配置 → 规则。
2. 添加规则集（如 GFWList、自定义规则）。
3. 设置匹配策略（DIRECT、PROXY、REJECT）。

4.3 日志与调试

如果遇到连接问题，可查看日志排查：
1. 进入 日志 选项卡。
2. 检查错误信息（如超时、认证失败）。
3. 根据日志调整服务器或网络设置。

第五章：常见问题与解决方案

5.1 连接失败怎么办？

  • 检查服务器信息：确保地址、端口、密码正确。
  • 更换协议：尝试 Shadowsocks 或 Vmess 不同加密方式。
  • 网络环境：某些 WiFi 可能屏蔽代理，可切换 4G/5G 测试。

5.2 如何提升速度？

  • 选择低延迟的服务器。
  • 启用 UDP 转发（若支持）。
  • 关闭不必要的规则以减少性能开销。

5.3 是否支持多设备？

Shadowrocket 仅限 iOS 设备，但可通过订阅方式同步服务器配置到其他客户端（如 Clash、Surge）。

第六章：安全与隐私建议

  1. 定期更换密码：避免长期使用同一组认证信息。
  2. 启用 TLS 加密：Vmess 协议建议搭配 TLS 以增强安全性。
  3. 避免公共 WiFi：即使使用代理，公共网络仍可能存在风险。

FAQ

Hiddify Next 的用户管理可以分组吗？
支持用户分组管理，可为不同组设置独立带宽、流量配额和节点访问权限。分组管理便于大规模用户维护，确保每个组的网络资源合理分配，提升整体管理效率。
VMess TLS 与 WebSocket 组合有哪些优势？
TLS + WebSocket 可将 VMess 流量伪装为 HTTPS，隐藏真实通信特征。结合策略组使用，可增强抗封锁能力，提高节点稳定性和访问速度，特别适合视频和游戏场景。
Surfboard 在 iOS 上无法连接时如何调试？
检查 iOS 的 VPN 配置权限是否授予，确认订阅链接或手动配置填写无误；查看 Surfboard 的日志或诊断页面，查看是否为 DNS 问题、TLS 错误或节点超时，并尝试切换节点或重启应用。
Hysteria2 多路复用对短连接性能有何提升？
多路复用允许多个短连接共享同一通道，减少握手延迟和资源消耗。适合高频短连接场景，如游戏和即时通讯，可提高吞吐量和连接稳定性，优化整体网络体验。
如何配置 Sing-box 使用 DoH 加密 DNS？
在 dns 模块中添加类型为 doh 的上游，如 `https://1.1.1.1/dns-query`，并指定 bootstrap 地址。启用加密 DNS 可防止 DNS 泄露并加快国际解析速度，提高整体隐私保护。
Sing-box 的策略组如何实现按域名分流？
Sing-box 支持根据域名规则匹配流量，将不同网站或应用流量分配到指定节点。结合策略组自动切换低延迟节点，可优化访问速度，保证网络稳定性和流畅体验。
VLESS + XTLS 在高延迟移动网络的优势？
XTLS 模式减少握手次数和加密开销，适合高延迟或不稳定移动网络。结合策略组和节点切换，可提高网页浏览、视频播放和游戏连接的稳定性和流畅度。
PassWall2 如何实现按域名分流？
PassWall2 可通过域名规则匹配请求，将流量分流至指定节点。结合策略组和自动测速，可让不同网站走不同节点，实现加速和优化访问速度的效果。
SSR 如何手动导入节点？
SSR 节点通常以“ssr://”链接形式提供。用户可在客户端中点击“添加节点”或“导入链接”，粘贴该字符串后保存即可。程序会自动解析服务器地址、端口、加密方式等参数。
Trojan 协议的安全性如何？
Trojan 使用与 HTTPS 类似的 TLS 加密通道，使其数据流难以与普通网页访问区分。它兼具隐蔽性与安全性，几乎无法被防火墙检测。Trojan 协议的主要优势在于稳定、安全、兼容性强，因此广受高级用户青睐。
